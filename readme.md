# EuroScore

Football badge from TheSportsDB APIFootball badge guessing game built with Node.js, Express, PostgreSQL and EJS.

## Technologies

- Node.js
- Express
- PostgreSQL
- EJS
- JavaScript
- API calling

## Installation

npm install

Create a .env file and configure your database connection.

npm start

## Features

- User registration
- User login
- Football logo guessing game
- Difficulty levels
